# FullHDFilmizlesene sağlayıcısı

Dizilla'dan tamamen ayrı bir CloudStream modülüdür; Dizilla sınıflarını veya yardımcılarını kullanmaz.

- Site: https://www.fullhdfilmizlesene.now/
- Sağlayıcı adı: FullHDFilmizlesene
- Kapsam: film arama, ana sayfa kartları, film detayları ve iframe/scx kaynaklarını CloudStream extractor sistemine aktarma.
- Kök Gradle ayarları modülü otomatik dahil eder.

Arama yüzeyi ve scx biçimi açık kaynak referanslarından araştırıldı; Kotlin uygulaması bağımsız yazıldı. Tüm oynatıcı host'ları canlı ortamda henüz doğrulanmış değildir; GitHub Actions derlemesi ve gerçek CloudStream oynatma testi gereklidir.
